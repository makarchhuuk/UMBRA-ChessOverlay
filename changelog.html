# Changelog All notable changes to Umbra. Format loosely follows [Keep a Changelog](https://keepachangelog.com/). ## 1.0.3 — first public release First public build: a Firefox extension plus a Windows overlay helper. The internal build before the public release was numbered 5.5.0 — numbering restarts at 1.0.3 here. ### Added - `overlay/` — Windows helper, now part of this repository. Tray-only control: left or right click opens the menu (Restart, Quit, toggle arrows, stop frame, status, log). - **Stop frame** switch in the tray: keep the arrows out of screen capture, or show them on stream. - Hotkeys: `Ctrl+Alt+H` toggles the arrows, `Ctrl+Alt+Q` quits the helper. - `README.md`, `CHANGELOG.md`, `CONTRIBUTING.md`, `LICENSE`, `.gitignore`, README banner. ### Changed - Renamed to **Umbra**, new logo: black rounded tile with a knight. - Popup redesigned: black, hairline separators, no gradients or glows. - Orange arrow for the suggested move, black arrow for the predicted follow-up, and a thin black frame around the piece to move next. The black marks stay visible while the opponent is thinking. - Tray menu reordered — **Restart** and **Quit** are the first two items. - Log file moved to `%TEMP%\umbra-arrow.log`, truncated when it grows past 2 MB. - Extension ID is `umbra-overlay@local`; settings are not carried over from earlier builds. ### Removed - Floating control panel in the top-right corner of the screen. - `analytics.js` and its remote endpoint — nothing is uploaded anywhere now. - Upstream `chessbot-overlay` package that was not part of this fork. - Lichess support inherited from upstream — the site adapter was dropped before this release. ### Fixed - Helper crashed on `AddHook` because `$source` (the icon bitmap) shadowed the `HwndSource` variable. - Grey flash on popup buttons during first paint (native button theming showing through). ## Before 1.0 Inherited from [bogenc/ChessBot](https://github.com/bogenc/ChessBot): the engine injection, the arrow bridge, the popup controls, and the Lichess variant that was later removed from this fork.
